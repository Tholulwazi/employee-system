# Employee Management System — Adabas & Natural

An employee management application developed using **Software AG Natural and Adabas** to manage employee records and demonstrate mainframe-style data processing, database operations, and enterprise application development.

## Overview

The Employee Management System is built entirely with Natural programming language and Adabas database technology. It demonstrates how enterprise applications can use Natural for business logic and Adabas for storing, retrieving, updating, and managing employee information.

The project focuses on structured data processing, employee record maintenance, database access, and menu-driven application workflows.

## Technology Stack

- **Programming Language:** Software AG Natural
- **Database Management System:** Adabas
- **Development Environment:** NaturalONE / Software AG Natural development environment
- **Version Control:** Git and GitHub

## Features

- **Employee Search:** Search for employee records using available identifiers.
- **Employee Information:** Display employee personal information.
- **Company Information:** Display employee company or employment details.
- **Employee Record Retrieval:** Retrieve records using appropriate Natural and Adabas data access statements.
- **Record Updates:** Modify employee information through controlled update operations.
- **Menu-Driven Navigation:** Navigate between employee search, personal information, company information, and update functions.
- **Adabas Data Access:** Work with persistent employee data stored in Adabas.
- **Structured Natural Programming:** Organize application logic using Natural statements, processing loops, conditions, and subroutines where appropriate.

## System Functionality

The application is designed around employee record management.

| Function | Description |

## Getting Started

### Prerequisites

To run or maintain this application, you will need:

- Access to a compatible Software AG Natural environment
- Access to an Adabas database containing the required employee data
- NaturalONE or another supported Natural development environment
- The application's Natural source code
- Appropriate database and library permissions

### Installation and Execution

1. Clone or download this repository.
2. Open the Natural source code in your supported Natural development environment.
3. Configure access to the appropriate Natural library and Adabas database.
4. Ensure the required employee files and field definitions are available.
5. Build or catalog the required Natural programs according to your environment.
6. Execute the main program and test the available employee management functions.

**Note:** Exact setup steps depend on the target Natural environment, library configuration, and Adabas file definitions.
